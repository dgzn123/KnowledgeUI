# 状态与步进

- `state` 保存用户能修改的数值、字符串或布尔值。给出合法默认值。使用滑块或步进器时，在状态声明中给出有限 `min`、`max` 和正 `step`，默认值位于步进格点。注记单位，避免不同维度共用含混变量名。
- `data` 保存只读表格、轨迹、帧和示例点。`computed` 保存由输入派生的值，支持前向依赖；依赖必须无环，名称不能重复或遮蔽内置名。先规划从输入到结果的数据流，多个控件和图形从同一派生值读取。
- `bind` 直接写当前模型的状态名。按钮的 `action.type` 可为 `set`、`reset`、`toggle`、`increment`，目标与字面参数遵循 [组件结构](components.md#button)及相应状态类型。 `select` 选项取值和绑定状态类型一致，默认值属于选项。
- `computed`、`when`、`repeat.items` 和函数系列的 `expr` 写原始表达式。其它字段按生成参考上的标记使用插值。形如 `'{{frames[step].lines}}'` 的完整插值保留数组类型，`'步骤 {{step}}'` 生成字符串。绑定结果仍需符合字段类型与合法范围。
- `^` 是右结合的幂，`-2^2` 为 `-4`。逻辑运算和三元分支使用布尔条件。字符串可用 `fmt(n, 2)` 格式化两位小数，数值目标直接绑定数值。`len` 和数学函数按协议白名单使用。优先用简单解析式或读表，保护分母零点、对数正值和数组索引。
- `repeat: {items: frames, as: frame, index: i}` 适合按只读帧数组展开同结构项。当前实例、其 `when` 与后代可以用别名；索引从 0 开始。模板体可以读取本次调用解析的只读参数。

## 离散过程

先列可独立复核的帧表，标出改变的字段和该帧解释的因果步骤。用 `stepper` 写入整数状态 `step`，范围为 `0…labels.length - 1`、步长为 1。把帧表声明为 `data.frames`，通过表达式 `frames[step]` 驱动文本、图和代码。代码行号从 1 开始，`highlight` 接收行号或闭区间数组。若使用 `sequence`，将消息与教学步骤逐一对齐并核对 `activeStep`。

默认停在易解释的帧。需要播放的演示允许暂停、逐步查看及重置。检查所有帧均能访问、默认帧可恢复、跨帧变化与说明一致。用固定位置展现同一实体，帮助读者追踪真正发生的变化。可参考[二分查找](../examples/lower-bound.md)的帧表和代码联动。

对连续模型记录默认值、上下限、临界点两侧、代表性中间值及重置结果。核对显示精度与实际计算，决定状态变化是否保持图表量程一致。对非法输入按宿主实际表现记录诊断或约束行为。
