# 图形与可视化

## 按读图任务选择

| 读图任务 | 组件与编码 |
|---|---|
| 比较离散类别或取值的量 | `chart` 的 `bar`，说明数值横轴对应哪些类别，纵轴使用合适的基线 |
| 读随有序变量变化的趋势 | `chart` 的 `line` 或 `function`，交代连线和插值的含义 |
| 比较点云或样本对应关系 | `chart` 的 `scatter`，注明数据出处和单位 |
| 强调累积量或基线区域 | `chart` 的 `area` 或 `regions`，说明填充代表的量或范围 |
| 看空间关系、尺寸、位置或结构剖面 | `svg`，显式规划坐标和标签 |
| 看消息先后和发收双方 | `sequence`，按行记录请求、返回和本地步骤 |
| 看节点关系、指针改向、树或状态转移 | `graph`，给出稳定 ID 和显式坐标或网格 |
| 精确查值或同列对比 | `table`，行列对齐，给出缺省项的含义 |

图名说明观察对象，轴标给出量名与单位，正文说清读图后应能判断什么。多序列同时提供图例或文字标识。先用给定输入手算几个参照点，用 `markers` 或 `referenceLines` 指出重要位置。跨数量级比较可用 `log` 轴，对数轴的数据和范围端点必须大于零。函数系列的采样变量是 `x`，为其指定有限横轴范围，测试分段接缝、分母为零或根式越界等情形。v1 函数曲线是有限点采样，遇到奇点或不连续区间时按连续定义域分段或给出限定区间的离线数据。结构支持项见 [chart](components.md#chart)。

## SVG 坐标规划

1. 在 YAML 之前先画布局草图，确定 `viewBox: "minX minY width height"`。宽高大于零，坐标单位为 SVG 用户单位。默认向右为 x 正方向、向下为 y 正方向，显示实际物理方向时用箭头和标签明确。
2. 先放主结构和箭头，再放标签与刻度。为线宽、箭头和文字边缘预留余量，缩至窄容器检查重叠和裁切。如果图不按比例绘制，在图旁写明。关键尺寸和关系在 Markdown 中能直接读到。
3. 用 `group` 管理共用变换，`transform` 采用结构化的平移、缩放和旋转。需要裁剪时先声明局部 `clip` 定义，其 `elements` 直接列出形状或文字，再以定义 ID 引用。按组件参考使用声明图元、主题色和有界几何。已有电路等领域符号用 `use-symbol` 调用内置资源。 [SVG 图元结构](components.md#svgelement)

## 离散图解

`graph` 的行列是零基索引，坐标表示节点左上角。先固定可比较的节点位置，再选直线、正交或曲线边。借助网格间距和节点尺寸避免交叠。逐步修改指针时确认可见边的端点仍存在，图外解释箭头表示的方向。 `sequence` 参与者按声明顺序排成列，消息按行列出。可用消息的 `step` 把多条消息归到同一教学步，用 `activeStep` 绑定当前高亮。检查起点、回退和最后状态。 [graph](components.md#graph) · [sequence](components.md#sequence)
