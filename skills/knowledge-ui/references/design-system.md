# 教学笔记排版

- 从原生 Markdown 的阅读顺序出发。用标题表示知识层级，以留白和简短注释说明图与正文的关系。单个概念只需一个主要视觉焦点，例如关键值、当前状态或需要比较的一组结果。
- `stack` 适合有先后顺序的块。需要同屏比较时才用 `grid` 或 `compare`，在窄容器保持单列仍可理解。窗口宽度相同也可能有不同的块宽度，例如编辑器分栏。
- `tabs` 适合并列的替代视图，`collapse` 适合次要推导、自测解析或补充条件。核心条件和结论留在一直可见的正文。用局部说明和轻量分隔保持开放排版，减少视觉边框、重复标题与装饰标签。
- 默认采用主题提供的正文和辅助色。`info` 表示重点、当前选择或交互焦点，`success` 表示通过或正确，`warning` 表示边界和需注意的条件，`danger` 表示错误或异常。状态同时用短标签、箭头、线型或文字说明表达。
- 给控件可见标签、单位和必要的操作说明。可为需要解释的组件提供 `ariaLabel`。用键盘移动和触发控件，在触控尺寸下确认操作、拖动和局部滚动。把长公式、代码和表格的可读性与坐标图的等比缩放纳入窄容器检查。
- Preview 可检查浅色、深色和 375px 等预设。遇到局部滚动时检查长内容的最后一列或最后一行能否到达，确认页面本身保持可读。宿主的 LaTeX、链接和代码分词可能有不同表现，分别记录实际观察结果。
